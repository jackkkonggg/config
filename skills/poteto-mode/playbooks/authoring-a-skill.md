### Authoring or modifying a skill

**You own the skill's voice.** Agent-facing prose has a higher bar than human prose; unhelpful sentences become instructions.

1. Use the environment's skill-authoring skill.
2. Validate the skill: frontmatter has `name` and `description`, referenced files exist, cross-skill links resolve.
3. Test cases if structural; skip if subjective.
4. Run **Opening a PR**.

When in doubt, delete. Prose earns its keep by changing a decision. Keep the
entrypoint focused on routing and put detailed guidance in selectively loaded
references. Prefer checks, metadata, and configuration over repeated prose.

**Reply:** summary of the skill, key design decisions, validation notes.
