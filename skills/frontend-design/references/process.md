# Design Process

For an open-ended design, write a compact plan before implementation:

1. Define a small token set for color, typography, spacing, and surfaces.
2. Compare two or three layout shapes with short prose or ASCII wireframes.
3. Choose the signature element and explain how it serves the brief.
4. Remove any choice that could be reused unchanged for an unrelated product.
5. Build from the selected plan instead of improvising a new direction in code.
6. Render and critique the result. Remove decoration that does not serve the
   page's job.

Keep planning proportional to the task. A scoped component change does not need
a page-level design exercise.
