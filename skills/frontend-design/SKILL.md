# Frontend Design

Ground the design in the product, audience, content, and existing design
system. Preserve established components and tokens unless the user asks for a
new direction.

Load only the guidance needed:

| Need | Load |
| --- | --- |
| Establish the visual direction, hierarchy, typography, layout, or signature element | `references/direction.md` |
| Plan and critique an open-ended design before building | `references/process.md` |
| Write or revise interface copy | `references/writing.md` |

Choose a coherent direction and spend visual emphasis deliberately. Structure
must communicate real content rather than decorate it. Match implementation
complexity to the chosen direction.

Build the requested states and responsive behavior. Preserve visible focus and
reduced-motion behavior. Render the result, inspect it at representative
viewports, and revise clipping, hierarchy, spacing, and inconsistency before
finishing.
