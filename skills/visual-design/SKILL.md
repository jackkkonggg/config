# Visual Design

Inspect the existing design system, preserve its tokens and implementation
approach, and load only matching references.

- **Holistic review:** `references/interface-review.md`, then one domain at a time.
- **Accessibility:** the matching `accessibility-*.md` file for focus,
  keyboard, forms, semantics, screen readers, hit areas, zoom, or motion.
- **Layout:** the matching `layout-*.md` file for grouping, alignment, adaptive
  spacing, breakpoints, RTL, or reading order.
- **Writing:** `references/writing.md` for labels, errors, settings, empty
  states, or copy.
- **Color:** the matching `references/color-*.md` file,
  `references/palette-generation.md`, `references/accessibility-contrast.md`,
  or `references/gamut-and-tailwind.md`.
- **Typography:** the matching `typography-*.md` file for font choice,
  OpenType, scale, spacing, wrapping, accessibility, or CSS syntax.
- **Polish:** the matching `references/polish-*.md` file.

For broad work, inspect first and load only evidenced concerns. During a full
review, retain reduced findings before loading the next domain. Keep edits
scoped and verify the rendered result.
